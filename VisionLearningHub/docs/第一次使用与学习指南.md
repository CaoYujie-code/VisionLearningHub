# 第一次使用与学习指南

> 当前完整路线与新增题目见 [0.4.0 学习路线](学习路线-0.4.0.md)。

## 第一节课怎么学

1. 双击工程中的 `启动学习平台.cmd`，进入“学习路线”。
2. 阅读 S00“从数组开始”，理解输入、返回值、数组与边界情况。
3. 打开 P01，先读“输入 / 输出约定”：这道题要返回**原始下标**，不是面积本身。
4. 在代码编辑器中逐行完成 `solve(image, params)`，用自己理解的循环与条件实现。
5. 点“运行样例”，对比输入与输出，检查是否把阈值相等的元素保留下来。
6. 如果失败，先读逐项检查，再看错误类型和定位到的行；不急着换一整段代码。
7. 点“多样例验收”，平台会检查 5 组数据，包含空输入等边界情形。
8. 在笔记中回答：返回下标和返回数值有什么区别？为什么条件是大于等于？
9. 进入 P02，把循环操作逐步迁移到 NumPy 的切片和统计。

练习编辑器支持自动保存、Ctrl+S、Tab/Shift+Tab 缩进、Enter 自动缩进和 Ctrl+Enter 运行。课程自查与笔记也会自动保存。看到“已保存到本机”后再关闭页面最稳妥；保存失败时页面会提示。

## 四个新增 OpenCV 章节

顺序是 **S12 → S13 → S14 → S15 → S03**。每个练习都能先运行一组样例，再做五组边界验收：

- **V01 灰度直方图**：数出 0–255 各亮度的像素，再看直方图为何看不到目标所在位置。
- **V06 Otsu 自动阈值**：从全图分布提出一条界线，验证阴影和小目标为什么会误导它。
- **V02 局部自适应阈值**：改变窗口和 C，比较渐变光照下的小细节、背景噪声与前景孔洞。
- **V03 中值滤波**：观察它如何去除椒盐点，以及窗口变大后怎样损失细线。
- **V04 Sobel 梯度**：分别计算 gx、gy 和幅值，区分方向、强度与物体区域。
- **V05 积分图**：从四角累计值计算 ROI 的像素和、平均亮度与面积。

这条路线从“看分布”走向“分割、去噪、测变化、算区域统计”。做完后再学习 Canny、轮廓与几何；不要把梯度图当作完整目标掩膜。

## 每类处理适合什么场景

- **全局阈值**：前景与背景亮度差异明确、光照较稳定。阴影和反光可能使同一目标断裂。
- **HSV 分割**：颜色有明显差异、背景条件可控制。目标与背景同色时，单靠颜色无法区分。
- **高斯平滑**：抑制细碎噪声。过强平滑会抹掉纹理、角点和相邻物体间的间隙。
- **形态学**：修补已经大体正确的二值掩膜。不能凭空恢复分割中丢失的真实目标。
- **Canny**：寻找局部变化明显的边界。输出是边缘，不是填充区域，也不是语义识别结果。
- **轮廓与几何**：将区域转换为面积、中心、顶点等描述。先检查掩膜质量与面积退化。
- **YOLO 等学习方法**：依靠样本学习目标外观，需要有代表性的标注数据、独立验证和部署条件。
- **Linux 与嵌入式**：解决采集、运行环境、进程、设备和部署问题，需要与视觉算法一起验证完整链路。

在“图像实验室”中选择 12 种处理方法之一，并选择输入样例；修改一个参数，再点“运行实验”。参数变动后旧图暂时保留，页面会提醒重新运行。平均像素值、非零比例都不是准确率。

## 如何判断自己真的掌握

通过一道题之后，尝试做三件事：

1. 不看参考代码，用自己的话解释每个步骤和返回值。
2. 预测一个失败样例，例如阴影、空输入、坐标越界或核过大，然后验证预测。
3. 换一个输入或参数仍能运行，解释为什么结果变化。

“已验收”只代表当前代码及其前置代码通过预设样例，不是对任意输入正确性的证明。修改代码后需要重新验收，原有报告仍以历史快照保存。

## 卡住时的排查顺序

先核对输入/输出约定，再检查 shape、dtype、颜色顺序与坐标单位；之后查看中间图，最后再调整参数。组合题会调用你已保存的前置代码，前置关卡未完成时，要先定位那一关。

提示可逐条展开。参考实现需要主动打开，只用于对照，不会自动填写编辑器。超过 25 秒的练习会被终止，你也可以主动停止。刷新页面后，顶部会重新显示仍在运行的任务。

## 资料、笔记与迁移

“学习资料库”有 35 份官方入口，每份附带阅读任务。先看与当前问题有关的小节，再回来实践。外部文档可能随版本变化，应对照“记录与设置”中的本机版本。

定期在“记录与设置”下载学习备份。恢复前会自动保留原状态备份；新平台的数据目录独立，正常使用不会覆盖旧 `VisionLearningStudio` 的进度。

“导出练习代码”得到每道题的 Python 文件与 T14 离线检测入口。未实现的题仍包含 TODO，导出不意味着所有关卡已完成。请先完成 T14 及其前置代码，再按导出包 README 测试自己的图片。

## 下一阶段适合增加的能力

1. **真实图片题库**：光照、遮挡、透视等带标注素材，训练/验证分离的验收集。
2. **YOLO 推理实验**：固定模型、预处理和后处理，显示置信度、类别过滤与误检漏检。
3. **小规模训练实验**：数据检查、训练日志、验证指标与权重管理，明确资源和下载需求。
4. **Linux 终端任务**：连接明确的 WSL 或设备环境，检查真实命令退出码、构建产物与日志。
5. **板端部署**：选定板卡与 SDK，再实现模型转换、上传、运行及 PC/板端对比。

本版已实现学习与 CPU 练习闭环；以上能力仍属于后续工作。
