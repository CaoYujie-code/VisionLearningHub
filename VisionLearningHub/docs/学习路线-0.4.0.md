本版共 24 章、44 道可运行题、35 份官方资料。已有题号与验收规则不变，新增题使用 `V07–V14`、`Y04–Y05`、`L02–L03`。网页与 VS Code 使用相同课程；VS Code 中打开练习会定位到真实 Python 文件，支持保存、运行、调试与多样例验收。

## 每次学习怎么进行

1. **读任务**：先写清输入的 shape、dtype、坐标顺序和输出格式。
2. **画例子**：用小数组或简单方块手算一个正常输入和一个边界输入。
3. **自己敲**：从 TODO 开始，只查所需的官方函数参数。先运行样例，再做多样例验收。
4. **解释失败**：查看原图、中间输出和失败项，每次只修改一个参数或一条规则。
5. **迁移验证**：换光照、噪声、位置或空输入；保存一份成功例和一份失败例。
6. **留下记录**：在课程笔记里写出“何时适用、何时失效、我如何证明”。自查勾选表示理解情况，通关表示当前代码通过课程样例，二者分开保存。

## 把算法选择变成问题

| 观察到的现象 | 可以先试 | 用什么证据判断 |
| --- | --- | --- |
| 固定尺度目标外观稳定 | 模板匹配 | 位置误差、无目标分数、旋转缩放后的失败例 |
| 红色目标总漏掉一部分 | 检查 HSV 环绕范围 | 两侧色相、灰色和暗区的对照掩膜 |
| 两块零件被计成一块 | 检查连通关系与清理操作，再考虑种子分割 | 掩膜、距离图、种子图、最终标签逐级比较 |
| 图片局部太暗 | Gamma/CLAHE 与原始处理做对照 | 下游分割或检测指标；不能只看视觉效果 |
| 运动物体出现两道影子 | 理解帧差覆盖新旧位置 | 前后帧、差分图、时间戳；必要时改用跟踪 |
| 训练分数高，现场表现差 | 先检查采集组泄漏与场景覆盖 | 分组清单、独立现场样本、分场景错误统计 |
| 摄像头画面错行或花屏 | 检查实际像素格式和 bytesperline | 逐行字节数、缓冲区大小、正确的格式转换 |
| 模型快但应用卡 | 测全链路、排队与 P95 | 逐帧阶段时间、吞吐、预热与稳定段数据 |
