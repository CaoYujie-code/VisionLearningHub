## 逐块手敲

进入工程，选择“分块引导 → 算法结果与位置”。展开当前小任务，按输入、动手实现、验证证据实施；函数和模块名自行设计，继续使用原生OpenCV、NumPy与Python标准库。

例如E07从ORB特征开始，依次检查描述子、Hamming近邻匹配、ratio筛选、RANSAC内点和模板四角投影。不要一次把所有步骤写完才运行。可以新建普通study.py，先把当前步骤的数量、中间图和异常返回检查清楚，再接入自己的pipeline.py。

| 层级 | 如何验证 | 是否计入工程通关 |
| --- | --- | --- |
| 专属小任务 | 自己运行模块，保存中间图和证据，勾选自查 | 否 |
| 方法对比 | 固定输入、只改变待比较方法，记录误检/漏检/误差与适用条件 | 否 |
| 故障维修 | 先构造失败输入，再修复给出的错误代码片段并验证边界 | 否 |
| io/detect/render/batch任务块 | 平台读取当前源码与输出文件自动检查 | 否 |
| accept完整验收 | 自己的main.py通过5批完整教学输入 | 是 |

独立挑战可以跳过引导直接交付完整工程。两种模式共用源码；修改后应重新验收。导出的GUIDED_LEARNING.md包含专属任务、对比与维修说明，可离开平台继续练习。

## E09：相机标定与畸变校正

先学A03透视矫正与T13像素到平台，区分平面变换、像素比例与镜头标定。官方入口：[OpenCV相机标定教程](https://docs.opencv.org/4.x/dc/dbb/tutorial_py_calibration.html)。

每批有12张不同姿态棋盘、1张无棋盘空图、1个故意损坏文件。图片由已知针孔相机模型渲染，包含径向/切向畸变；不是相机实拍素材。公开配置为9×6内角点、25mm方格、640×480图片。生成器真值仅供判题，不写入学生输入目录。

建议步骤：

1. 读图并检查分辨率、点数与错误类别。
2. findChessboardCorners检测内角点，cornerSubPix细化，检查点序。
3. 生成同序的物平面点，收集至少10张有效不同姿态，calibrateCamera求内参和畸变。
4. projectPoints计算逐点二维残差，每图计算RMSE并解释最大误差来源。
5. 使用原matrix作为newCameraMatrix调用undistort；保存同尺寸图和参数，不裁剪。

results.json包含records与calibration。records逐图给出file、status、corners；坏图记录decode_failed。calibration给出3×3 matrix、5项distortion、image_size、rms、view_errors。详细阈值在工程交付约定中显示。

正式验收对比角点、焦距、主点及独立网格畸变，并重新计算每图误差和整体RMSE，检查确实交付了使用提交参数生成的校正图。只填写低误差数字、删除错误记录或原样复制图片不能通过。

detect块只要求角点与状态，不要求此时完成整批标定；标定、逐图误差和去畸变在batch/accept检查。render可先用标准中间结果单独学习可视化。

## 学完后迁移到自己的相机

固定分辨率、焦距和对焦设置，采集覆盖不同位置和倾角的棋盘，再运行导出的程序。记录参数、采集条件、失败视图和独立检验；不要把模拟棋盘上的低误差当作真实镜头精度。YOLO训练、Linux相机采集、SSH和板端联调仍是后续范围。
