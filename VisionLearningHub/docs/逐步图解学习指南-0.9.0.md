# 逐步图解学习指南 · 0.9.0

本版把首批 8 道基础题改造成可观察的分步课程，共 18 个步骤、27 组可选参数配置。其余基础题保留已有函数讲解和验收，尚未全部制作逐步图解。

## 从哪里进入

在 **基础练习** 选择下表中的题目，点击 **先逐步看图理解本题**，或选择 **逐步图解** 标签。建议首次从 T01、T02、T03 开始。

| 题目 | 步骤 | 应学会观察什么 |
| --- | --- | --- |
| T01 读图与像素 | 解码 → 尺寸与单通道 | BGR 顺序、shape、单个通道的明暗与原图颜色的关系 |
| T02 ROI 与坐标 | 圈出范围 → 切片 | 行列与坐标顺序、切片终点、局部点回原图 |
| T03 灰度与阈值 | 灰度 → 二值图 | 阈值提高后白色范围变化、黑字造成的孔洞、严格大于阈值 |
| T04 HSV 背景分离 | H 通道 → 背景 → 前景 | 三通道范围、背景和前景约定、低饱和度的限制 |
| T05 清理二值掩膜 | 开运算 → 闭运算 | 白噪点、小黑孔、真实细节和粘连风险 |
| T06 找到碎片 | 外轮廓 → 面积过滤 | 几何面积、底图与红色轮廓线、粘连和小噪点 |
| V03 椒盐去噪 | 中值滤波 → 差异图 | 噪声减少与细线损失、绝对差不等于质量分数 |
| V04 Sobel 梯度 | gx / gy → 幅值 | x/y 求导分支、梯度正负号、浮点原值与显示转换 |

## 推荐学习顺序

1. **读场景和目标**：先确认问题、交付结果和适用条件。
2. **预测**：读本步问题，在笔记中写下预期，不急于打开解释。
3. **看图**：对照处理前后，按“重点观察”定位变化。相同尺寸并排图支持同步滚动；可以放大 2 / 4 倍，也可单图切换前后。
4. **读代码**：联系本步原生函数调用与逐行说明，观察 shape、类型、实际最小值和最大值。
5. **改一个参数**：用固定 seed 17 样例重新运行。点“与默认参数对照”，比较同一步的真实输出。
6. **手敲**：切到“分步手敲”，参考代码默认折叠。写完、运行、导入每一步的数组。
7. **解释与挑战**：记录“预测—实测—适用条件”，能讲清楚后自评标记，再回原题独立编写并做多样例验收。

图解参数实验不会改动正式题目代码，也不会改变原题的输入 / 输出约定。教学样例是可重复的合成素材，不代表实物现场的全部情况。

## VS Code 中手敲

1. 选择实验参数，点击 **在 VS Code 打开分步代码**。
2. 平台在学习工作区的 `walkthrough-experiments/题号-课程版本-参数/` 创建普通文件。再次打开同一实验保留修改；不同参数和新版课程使用不同目录。
3. 编辑 `practice.py`：按本步讲解写处理代码，并取消该步三行保存代码的注释。
4. 点击 **运行我的分步代码**。插件使用配置的 Python 解释器，在原生终端任务中运行这个文件。等待终端执行结束。插件运行前将旧结果另存为 `results.previous-时间.zip`，即使新代码提前报错也不会误读旧包。
5. 点击 **读取我的步骤结果**。面板会读取该目录的 `results.zip`，并按步骤展示实际保存的数组。

例如完成 T03 第二步后，保存部分是普通 NumPy / 标准库代码：

```python
raw = io.BytesIO()
np.save(raw, mask, allow_pickle=False)
archive.writestr("step2.npy", raw.getvalue())
```

脚本不依赖平台自定义图像函数，也不替换 `exercises/T03.py`。可用 VS Code 的原生 Python 调试功能查看变量；本版新增按钮负责普通终端运行，不是专门的分步断点控制器。

## 浏览器或 PyCharm 中手敲

点击 **下载手敲实验包**，解压后打开 `README.md` 和 `practice.py`，使用已经安装 OpenCV 与 NumPy 的 Python 环境：

```text
python practice.py
```

在平台选择 **导入 results.zip**。即使只完成第一步，也可导入；缺失步骤明确显示“尚未运行 / 尚未保存本步结果”。每次运行重新生成包，避免混入上次运行的旧数组。文件内也提供 `reference.py`，需要对照时才主动打开或运行。

参数变化请在平台重新选择并下载对应实验包，保持输入、参数与课程标识一致。若手动改动 `params.json`，应自行确保记录一致；平台能验证导入包的题号、版本与输入标识，但不能证明本地代码实际采用了哪些参数或是否独立完成。导入参考代码输出也不会获得通关。

## 如何看数据和图片

- **教学演示**：平台执行随课程提供的代码，用于解释算法。
- **你的导入结果**：来自本地结果文件，不用教学图代填。导入时只读取数组，不执行上传代码。
- 同一步只在课程版本与参数一致时并排对照；不一致会提示重新选择或生成实验包。
- 类型和尺寸一致只是排查线索，不等于数值正确或整题通过。允许你自己选择其他合理实现，正式成绩仍由原题验收判断。
- HSV 的 H 单通道以原始 0～179 数值显示为灰度，不把 HSV 三通道冒充普通 BGR 照片。
- Sobel 原始数据保留浮点正负号；预览用红 / 蓝区分正负。每张图独立缩放，必须结合数值范围比较不同核尺寸的强度。
- 幅值预览按本图最大值映射到 255，计算使用的仍是原始数组。导入数组原件保存在学习数据目录的运行记录中，备份包含它们。
- ROI 裁剪后尺寸变化，同步滚动不再代表相同原图坐标，应用偏移公式对照。
