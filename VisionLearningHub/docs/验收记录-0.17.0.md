## 本轮检查

- 未导入、空结果包、部分步骤缺失、数值差异、类型不一致分别展示，教学演示不填入自己的结果。
- 首个未保存 / 待检查步骤可跳转，键盘焦点移到讲解，保存步骤位置；刷新恢复已有笔记和导入状态。
- 不同参数、过期课程和缺少比较数据的记录不显示一致结论；过期与无比较分支通过拦截响应构造测试状态。
- 第一步漏保存、第二步存在差异可同时定位；导入空结果包后不复用上次数组。
- 空数组没有数值范围；两边空数组一致仍提示需要有结果的输入。
- 八类显示方式分别解释；三通道非零计数、直方图非空灰度级和区域标签元素不当作物体个数。
- 实际导入小幅浮点数组，确认小的非零范围不再显示为 0.00。
- 窄屏、键盘操作和正式成绩不受影响；截图已目视检查。
- 新增测试最初假定完整回归中没有历史导入，完整套件暴露该假定后修正初始响应隔离，重新运行整套浏览器检查通过。
- 41 道课程定义逐项与上版一致；数据库结构、验收规则与学习记录键未变。无新增依赖，锁文件只修改根版本。

测试均使用隔离数据与 VS Code 配置，不改动真实学习记录和日常安装。未额外运行可选调试器断点专项。
