# 0.1.0 验收记录（历史版本）

本记录对应 0.1.0。0.2.0 新增的 V01–V06 六道课程练习及扩展后的图像实验室未纳入本次自动验收；旧版记录继续保留供查阅。

所有已记录的自动检查使用独立临时数据目录，未写入学习者的正式进度。旧工程 `VisionLearningStudio` 未被修改。

## Python / API 检查

`tests/test_platform.py` 覆盖：

- 26 道参考实现，共 130 组验收样例，包含空输入、退化条件等边界。
- 全部题目的输入预览、12 章任务映射和 24 份资料索引。
- 页面会话校验、跨来源请求拒绝、资源目录访问边界。
- TODO 失败、单次运行不计通关、多样例通过、代码改变后进度失效。
- 单任务互斥、后台任务恢复标识、主动停止和自动超时。
- 5 种真实图像处理 × 4 种输入，上传图片、非法参数和非法图片。
- 备份恢复、收藏/笔记恢复、非法路径与异常数据库拒绝、失败后保留当前数据。
- YOLO 标签、坐标、指标和离线日志的错误答案拒绝。

运行结果：7 组测试通过；26 道参考实现 / 130 组样例通过。

## 构建与浏览器

- TypeScript 严格检查：`npm run check`。
- 生产前端构建：`npm run build`。
- Chrome 真实浏览器：`tests/browser.mjs`，覆盖 13 项用户流程。
- 桌面视口：1440 × 1000；小屏幕：390 × 844。
- 学习路线筛选、课程阅读、立即切页后的笔记与自查保存。
- 资料搜索、收藏筛选、图像实验参数与结果更新。
- 代码缩进、自动换行与保存快捷键；TODO 错误定位、解答验收、修改代码使进度失效。
- 练习笔记持久化、历史报告与备份下载。
- 无限循环停止；刷新后继续定位运行中的任务。
- 六个主页面无水平溢出；浏览器无未处理异常和 HTTP 5xx。
- 额外检查 `tests/check_images.mjs`：桌面和窄屏预览图完整显示，无底部裁切。

截图与检查摘要保存在 `validation/`。截图中的进度来自测试数据，不是学习者成绩。

## 启动与停止

启动器通过本机健康检查识别学习空间，使用随机服务实例标识与控制令牌停止自己启动的服务。Windows 虚拟环境可能使用转发进程，因此不依赖启动父进程与实际服务进程 PID 相同。

本版验证的是 `.cmd` / Python 本机启动方式，没有验证独立 EXE。摄像头、YOLO 训练、Linux 终端和板端部署不在本轮已实现或已验收范围内。
