## 本轮修复

1. 直方图、Otsu、自适应阈值、Sobel 的展示代码补充灰度转换，复制运行不再出现未定义变量。
2. 直方图展示代码补齐背景颜色和基线，生成结果与页面一致。
3. V04 Sobel 判题严格检查浮点数组、形状和有限数值，不再将不符合约定的整数输出静默转换后判为通过。
4. V04 的前置练习调整为 T03、A01，避免要求先完成排在后面的 Canny 练习。
5. 实验室尚未运行新参数时，“去手敲练习”仍对应当前展示结果，避免跳到未执行的方法。
6. 页脚版本号更新为 0.2。

修复后重新执行新增专项测试、前端类型检查与构建，并完成浏览器和启动器检查。

## 复核入口与证据

```powershell
.\.venv\Scripts\python.exe tests\test_platform.py
.\.venv\Scripts\python.exe tests\test_acceptance_v020.py
npm run check
npm run build
```

上述两个 Python 测试会使用临时数据空间。浏览器测试 `npm run test:browser` 和图片检查 `node tests/check_images.mjs` 需要预先启动隔离服务：设置 `VLH_DATA_ROOT` 为独立测试目录，并设置 `VLH_TEST_URL` 为该服务地址。浏览器脚本会修改学习记录，不能对正式空间执行。

`tests/check_lifecycle_v020.py` 仅用于本轮已建立的测试空间：读取项目根目录 `.test-data-location.txt`，要求目标位于本项目 `.test-data/acceptance-v020-*`，检查该实例后将其停止。它不是正式空间的日常启动入口。

检查摘要：

- 浏览器结果（本机历史文件：`../validation/browser-results.json`）：23 项流程。
- 启动器结果（本机历史文件：`../validation/lifecycle-results.json`）：4 项检查及实际比较字段。
- 新增练习截图（本机历史文件：`../validation/06-v020-practice.png`）。
- 图像实验室截图（本机历史文件：`../validation/07-v020-lab.png`）。
- 窄屏练习截图（本机历史文件：`../validation/05-mobile-practice.png`）。

环境：Windows、Python 3.12、OpenCV 4.13.0、NumPy 2.3.5、本机 Chrome。测试过程中出现 Starlette 对 TestClient 所用 httpx 的弃用提示，不影响本轮结果；后续升级依赖时需处理。
