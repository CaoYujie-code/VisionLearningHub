## cv2.imdecode / np.fromfile：文件到图像

关联题：T01

调用：`image = cv2.imdecode(encoded, cv2.IMREAD_COLOR)`

| 参数 | 含义 | 选择 |
| --- | --- | --- |
| encoded | 压缩文件字节，不是像素 | 中文路径可先 np.fromfile(path,dtype=np.uint8)；下例内存编码无需外部文件 |
| flags | 解码模式 | IMREAD_COLOR 得 BGR；IMREAD_GRAYSCALE 得二维灰度 |

返回值：成功返回 H×W×3 uint8 BGR；坏文件可能返回 None 或抛出 cv2.error。shape 是属性，tolist() 将数组转为列表。

适合：读取本地照片、相机保存帧。

限制：压缩字节不能直接 reshape 成图像。

易错：检查 None 后再访问 shape；BGR 的 [0,0,255] 是红色。

```python
import cv2
import numpy as np

pixel = np.array([[[0,0,255]]],np.uint8)
ok, encoded = cv2.imencode('.png',pixel)
assert ok
image = cv2.imdecode(encoded,cv2.IMREAD_COLOR)
assert image is not None and image.shape==(1,1,3)
assert image[0,0].tolist()==[0,0,255]
print(image.shape,image[0,0].tolist())
```

预期：(1,1,3) [0,0,255]。

动手：改成灰度解码，预测 shape 少哪一维，再修改相应断言。

[官方资料](https://docs.opencv.org/4.x/d4/da8/group__imgcodecs.html)

## NumPy：shape、切片、copy、dtype

关联题：T01、T02、P02、V05、L02

调用：`roi = image[y:y+h, x:x+w].copy()`

| 参数 | 含义 | 选择 |
| --- | --- | --- |
| y/x | 行/列，先y后x | 终点不包含；先检查ROI非空和边界 |
| copy() | 独立存储 | 普通切片常为视图；保留原图时复制 |
| astype(dtype) | 改变类型 | 相减先转浮点避免uint8回绕；reshape只改形状，不缩放 |

返回值：ROI shape=(h,w[,channels])；mean求均值；count_nonzero计非零元素，多通道时不是像素数量。

适合：截取工作区、检查输入、区域统计。

限制：裁剪不自动将局部坐标转回原图，也不能替代缩放。

易错：局部点(u,v)回原图要加ROI起点(x,y)。

```python
import cv2
import numpy as np

image = np.arange(12,dtype=np.uint8).reshape(3,4)
roi = image[1:3,1:4].copy()
assert roi.tolist()==[[5,6,7],[9,10,11]]
roi[0,0]=0
assert image[1,1]==5
assert np.count_nonzero(roi)==5
print(image.shape,float(np.mean(image)))
```

预期：(3,4) 5.5；修改副本不改变原图。

动手：去掉copy再运行，解释保护原图的断言为何失败。

[官方资料](https://numpy.org/doc/stable/user/basics.indexing.html)

## cv2.cvtColor：颜色空间转换

关联题：T03、T04、A02、V13

调用：`gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)`

| 参数 | 含义 | 选择 |
| --- | --- | --- |
| src | 输入图像 | 本例uint8 BGR，转换常量必须匹配输入通道 |
| code | 从哪种空间转到哪种 | BGR2GRAY处理亮度；BGR2HSV用于颜色分割 |

返回值：灰度为H×W；HSV仍为H×W×3。标准uint8 HSV中H=0..179，S/V=0..255。

适合：边缘检测前转灰度，按颜色分割前转HSV。

限制：目标背景亮度相近但颜色不同时，灰度会丢失信息。

易错：二维灰度不能再次按BGR2GRAY转换。

```python
import cv2
import numpy as np

bgr = np.array([[[0,0,255],[0,255,0]]],np.uint8)
hsv = cv2.cvtColor(bgr,cv2.COLOR_BGR2HSV)
gray = cv2.cvtColor(bgr,cv2.COLOR_BGR2GRAY)
assert hsv[0,:,0].tolist()==[0,60]
assert gray.shape==(1,2)
print(hsv.tolist(),gray.shape)
```

预期：红色H=0，绿色H=60；灰度shape=(1,2)。

动手：把红色改为[255,0,0]，先判断是什么颜色再查看H。

[官方资料](https://docs.opencv.org/4.x/df/d9d/tutorial_py_colorspaces.html)

## cv2.threshold：固定阈值与Otsu

关联题：T03、V02、V06、V14

调用：`used, mask = cv2.threshold(gray, t, 255, cv2.THRESH_BINARY)`

| 参数 | 含义 | 选择 |
| --- | --- | --- |
| t | 亮度分界线 | 固定阈值按样本选；OTSU时设0，由函数估计实际阈值 |
| maxval | 选中像素输出值 | 掩膜常用255，不要误当阈值 |
| type | 前景方向与策略 | BINARY选>t；INV选<=t；OTSU与方向常量按位或 |

返回值：返回(实际阈值,新图像)两个值。本例uint8单通道，mask只有0/255。

适合：固定光照的明暗分割；双亮度群明显时尝试Otsu。

限制：局部阴影明显时全局阈值可能失效，考虑局部阈值。

易错：元组不是mask；等于阈值时BINARY为0。

```python
import cv2
import numpy as np

gray = np.array([[0,99,100,101,255]],np.uint8)
used, mask = cv2.threshold(gray,100,255,cv2.THRESH_BINARY)
assert used==100 and mask.tolist()==[[0,0,0,255,255]]
auto, m = cv2.threshold(gray,0,255,cv2.THRESH_BINARY|cv2.THRESH_OTSU)
assert np.array_equal(m,(gray>auto).astype(np.uint8)*255)
print(used,mask.tolist(),'Otsu=',auto)
```

预期：固定结果[[0,0,0,255,255]]；自动阈值看实测值。

动手：阈值改101，先预测值为101的像素，再比较BINARY_INV。

[官方资料](https://docs.opencv.org/4.x/d7/d4d/tutorial_py_thresholding.html)

## cv2.inRange / bitwise_not / bitwise_or：颜色掩膜

关联题：T04、T14、V13

调用：`mask = cv2.inRange(hsv, lower, upper)`

| 参数 | 含义 | 选择 |
| --- | --- | --- |
| lower/upper | 各通道上下限，含端点 | 标准HSV按H/S/V排列 |
| bitwise_not | 逐位取反 | 0/255掩膜可反转前景背景 |
| bitwise_or | 合并掩膜 | 红色拆[170,179]与[0,10]，两段均限制S/V |

返回值：inRange返回同宽高uint8单通道；要求所有通道同时在范围内。

适合：绿色工作台抠前景、色标识别。

限制：灰色/强反光处色相不稳定，需检查饱和度与亮度。

易错：lower的H=170、upper的H=10不能表示环绕范围。

```python
import cv2
import numpy as np

hsv = np.array([[[175,255,255],[5,255,255],[60,255,255]]],np.uint8)
a = cv2.inRange(hsv,(170,80,80),(179,255,255))
b = cv2.inRange(hsv,(0,80,80),(10,255,255))
red = cv2.bitwise_or(a,b)
assert red.tolist()==[[255,255,0]]
assert cv2.bitwise_not(red).tolist()==[[0,0,255]]
print(red.tolist())
```

预期：两个红色选中，绿色为0。

动手：把第二点S改10，解释H仍为5却不应选中的原因。

[官方资料](https://docs.opencv.org/4.x/df/d9d/tutorial_py_colorspaces.html)

## cv2.morphologyEx / getStructuringElement：形态学

关联题：T05、T14

调用：`clean = cv2.morphologyEx(mask, cv2.MORPH_OPEN, kernel)`

| 参数 | 含义 | 选择 |
| --- | --- | --- |
| op | 对白前景的操作 | OPEN去小白点；CLOSE补小黑孔，顺序影响结果 |
| kernel | 结构元素 | ones((3,3),uint8)是方形；getStructuringElement可选椭圆；核应小于要保留的细节 |
| iterations | 重复次数 | 先从1开始，多次操作加重几何改变 |

返回值：返回同尺寸图；本例uint8二值图。会改变边界，不是无损清理。

适合：分割后清除孤立点、补小孔。

限制：细线或窄间隙是目标时，大核会删除或连接真实结构。

易错：先确认白色代表前景。

```python
import cv2
import numpy as np

mask = np.zeros((11,11),np.uint8)
mask[3:8,3:8]=255
mask[1,1]=255
kernel = cv2.getStructuringElement(cv2.MORPH_RECT,(3,3))
clean = cv2.morphologyEx(mask,cv2.MORPH_OPEN,kernel)
assert np.count_nonzero(mask)==26 and np.count_nonzero(clean)==25
print(np.count_nonzero(clean))
```

预期：孤立点消失，方块保留25像素。

动手：把方块改为1像素宽线，预测能否保留。

[官方资料](https://docs.opencv.org/4.x/d9/d61/tutorial_py_morphological_ops.html)

## cv2.findContours / contourArea：边界与面积

关联题：T06、T14、V10

调用：`contours, hierarchy = cv2.findContours(mask, mode, method)`

| 参数 | 含义 | 选择 |
| --- | --- | --- |
| mask | uint8单通道 | 非零视为前景，本例0/255 |
| mode | 取哪些轮廓 | EXTERNAL只外边界；孔洞关系用TREE和hierarchy |
| method | 保留边界点方式 | CHAIN_APPROX_SIMPLE压缩直线点，不是多边形近似epsilon |

返回值：轮廓为点数组列表，常N×1×2；hierarchy为层级或None。contourArea为几何面积。

适合：独立工件的外形、几何面积筛选。

限制：粘连通常只有一个外轮廓，换模式不会自动分开。

易错：列表顺序不是身份；几何面积不同于像素面积。

```python
import cv2
import numpy as np

mask = np.zeros((8,8),np.uint8)
mask[2:6,2:6]=255
cs,h = cv2.findContours(mask,cv2.RETR_EXTERNAL,cv2.CHAIN_APPROX_SIMPLE)
assert len(cs)==1 and cv2.contourArea(cs[0])==9
assert np.count_nonzero(mask)==16
print(cv2.contourArea(cs[0]),np.count_nonzero(mask))
```

预期：几何面积9，白像素16。

动手：方块中心挖孔，比较EXTERNAL与TREE的数量和层级。

[官方资料](https://docs.opencv.org/4.x/d4/d73/tutorial_py_contours_begin.html)

## cv2.moments / arcLength / approxPolyDP：轮廓几何

关联题：T07、T14

调用：`m = cv2.moments(c); p = cv2.approxPolyDP(c, epsilon, True)`

| 参数 | 含义 | 选择 |
| --- | --- | --- |
| m00/m10/m01 | 面积矩/一阶矩 | m00非0时质心=(m10/m00,m01/m00) |
| arcLength(c,closed) | 周长，单位像素 | 闭合轮廓用True |
| epsilon | 近似允许误差，像素 | 可先试周长1%~3%，再测角点误差，不保证恰好4点 |

返回值：moments返回字典，arcLength返回浮点，approxPolyDP返回点数组，reshape(-1,2)方便遍历。

适合：碎片质心和角点、形状简化。

限制：非凸物体质心可能在外部；近似不等于物体分类。

易错：退化轮廓m00=0，不能直接相除。

```python
import cv2
import numpy as np

c = np.array([[0,0],[4,0],[4,2],[0,2]],np.int32).reshape(-1,1,2)
m = cv2.moments(c)
assert m['m00']!=0
center = (m['m10']/m['m00'],m['m01']/m['m00'])
p = cv2.approxPolyDP(c,0.02*cv2.arcLength(c,True),True)
assert center==(2,1) and len(p)==4
print(center,p.reshape(-1,2).tolist())
```

预期：质心(2,1)，四角保留。

动手：把epsilon改成周长一半，解释角点减少。

[官方资料](https://docs.opencv.org/4.x/dd/d49/tutorial_py_contour_features.html)

## NumPy：角度、旋转矩阵、平移

关联题：T08

调用：`out = (points-center) @ rotation.T + center + shift`

| 参数 | 含义 | 选择 |
| --- | --- | --- |
| deg2rad | 角度转弧度 | sin/cos接收弧度，不直接传90 |
| center | 旋转中心xy | 先减中心，旋转后加回 |
| @ rotation.T | 行向量乘转置 | 图像y向下，视觉转向按坐标约定判断 |

返回值：N×2浮点坐标，变换点集不等于重采样图像。asarray(...,float)避免整数截断。

适合：碎片顶点旋转、平面几何变换。

限制：透视显著时旋转平移不足。

易错：旋转中心错会导致绕原点跑走。

```python
import cv2
import numpy as np

points = np.array([[1,0],[0,1]],float)
a = np.deg2rad(90)
r = np.array([[np.cos(a),-np.sin(a)],[np.sin(a),np.cos(a)]])
out = points@r.T+[2,3]
assert np.allclose(out,[[2,4],[1,3]])
print(out.round(3).tolist())
```

预期：[[2,4],[1,3]]。

动手：平移放到旋转前，手算为何结果一般不同。

[官方资料](https://numpy.org/doc/stable/reference/generated/numpy.deg2rad.html)

## cv2.fillPoly / count_nonzero：栅格覆盖

关联题：T09、T10

调用：`cv2.fillPoly(mask, [points_int], 255)`

| 参数 | 含义 | 选择 |
| --- | --- | --- |
| mask | 预分配画布 | zeros((height,width),uint8)，函数原地绘图 |
| pts | 多边形数组列表 | 浮点顶点先rint再astype(int32) |
| count_nonzero | 统计非零/真值 | 逻辑交集算重叠，逻辑并集算覆盖 |

返回值：fillPoly修改画布，count_nonzero返回数量；栅格面积含边界像素。

适合：拼图覆盖、碰撞近似、掩膜交并。

限制：亚像素精密测量不宜只依赖低分辨率栅格。

易错：重复填白不记录次数；统计重叠需分别画或用整数累计。

```python
import cv2
import numpy as np

a = np.zeros((8,8),np.uint8)
b = np.zeros_like(a)
cv2.fillPoly(a,[np.array([[1,1],[3,1],[3,3],[1,3]],np.int32)],255)
cv2.fillPoly(b,[np.array([[3,1],[5,1],[5,3],[3,3]],np.int32)],255)
i = np.count_nonzero((a>0)&(b>0))
assert i==3
print(i)
```

预期：共享边界列有3个重叠像素。

动手：第二块右移1像素，区分连续边界接触与像素重叠。

[官方资料](https://docs.opencv.org/4.x/d6/d6e/group__imgproc__draw.html)

## enumerate / append / return：筛选原下标

关联题：T10、P01

调用：`for index, value in enumerate(values): ...`

| 参数 | 含义 | 选择 |
| --- | --- | --- |
| values | 输入序列 | 空列表不进入循环 |

```python
import cv2

values = [5,10,12]
kept = []
for i,value in enumerate(values):
    if value>=10:
        kept.append(i)
assert kept==[1,2]
print(kept)
```

预期：[1,2]是下标，不是面积。

动手：试空列表、恰好等于阈值，再把>=换>比较。

## np.rot90 / mean / argmin：小图案比较

关联题：T11、V12

调用：`score = np.mean((patch.astype(float)-template.astype(float))**2)`

| 参数 | 含义 | 选择 |
| --- | --- | --- |
| astype(float) | 提升类型 | 避免uint8差值/平方回绕 |
| rot90(template,k) | 旋转k个90度 | 非方形旋转后宽高交换 |
| argmin(scores) | 最小分数下标 | 均方误差越小越像；同分取第一个，另需拒识阈值 |

返回值：均方误差是浮点；argmin是索引，分数不是概率。

适合：尺寸对齐、光照接近、种类有限的小图案。

限制：尺度、透视或光照差异大时像素差会失效。

易错：先几何归一化，不同尺寸不能直接相减。

```python
import cv2
import numpy as np

t = np.array([[0,50],[100,255]],np.uint8)
p = np.rot90(t)
scores = [float(np.mean((p.astype(float)-np.rot90(t,k).astype(float))**2)) for k in range(4)]
assert int(np.argmin(scores))==1 and scores[1]==0
print(scores)
```

预期：索引1对应90度旋转，误差0。

动手：给patch整体加亮度（先转浮点再clip），观察误差。

[官方资料](https://numpy.org/doc/stable/reference/generated/numpy.rot90.html)

## np.median：跨帧稳健统计

关联题：T12

调用：`stable = np.median(points, axis=0)`

| 参数 | 含义 | 选择 |
| --- | --- | --- |
| points | 同一对象的多帧坐标 | 先按身份对齐，不能按检测列表下标 |
| axis=0 | 跨帧分别统计x/y | None会把x/y混成一个标量 |
| window | 帧数 | 窗口越长一般更稳但响应更慢 |

返回值：N×2沿轴0取中位数得到2项；偶数项中位数可能小数。

适合：静止工件定位抑制离群点。

限制：持续运动会滞后，身份混乱不能靠中位数修复。

易错：别混合像素和毫米坐标。

```python
import cv2
import numpy as np

p = np.array([[10,20],[11,21],[500,800]],float)
s = np.median(p,axis=0)
assert s.tolist()==[11,21]
print(s.tolist(),p.mean(axis=0).tolist())
```

预期：中位数[11,21]；均值被离群点拉偏。

动手：换成连续移动的三帧，解释中位数不等于最新位置。

[官方资料](https://numpy.org/doc/stable/reference/generated/numpy.median.html)

## np.linalg.matrix_rank / lstsq：仿射拟合

关联题：T13

调用：`coef, residuals, rank, singular = np.linalg.lstsq(design, target, rcond=None)`

| 参数 | 含义 | 选择 |
| --- | --- | --- |
| design | 每行[u,v,1]，N×3 | column_stack加常数列，至少三组不共线点 |
| target | N×2对应坐标 | 点序一一对应、单位固定 |
| rcond=None | 库默认秩判定策略 | matrix_rank(design)<3时拒绝退化输入 |

返回值：coef为3×2；新点扩为[u,v,1]再@coef。residuals有时为空，不能假设总有误差值。

适合：近似平面仿射映射、像素到平台坐标。

限制：透视/镜头畸变明显、点共线时不足。

易错：用未参与拟合的检查点评估。

```python
import cv2
import numpy as np

uv = np.array([[0,0],[1,0],[0,1],[1,1]],float)
d = np.column_stack([uv,np.ones(len(uv))])
assert np.linalg.matrix_rank(d)==3
coef,_,_,_ = np.linalg.lstsq(d,uv*[2,3]+[10,20],rcond=None)
pred = np.array([[2,3,1]])@coef
assert np.allclose(pred,[[14,29]])
print(pred.round(6).tolist())
```

预期：独立检查点[[14,29]]。

## NumPy：shape、切片、copy、dtype · 理解自测

## cv2.threshold：固定阈值与Otsu · 理解自测

灰度像素值是100，阈值100，maxval=255，使用THRESH_BINARY。输出是多少？

- **A.** 0
- **B.** 255

## cv2.inRange / bitwise_not / bitwise_or：颜色掩膜 · 理解自测

要在标准uint8 HSV中选红色H=170..179或0..10，应该怎么写？

- **B.** 分别inRange两段，再bitwise_or，并在两段限制S/V

## cv2.morphologyEx / getStructuringElement：形态学 · 理解自测

- **B.** 对掩膜做取反就能去掉白噪点

- **A.** 检测到变化，可能是光照而不是物体运动
- **B.** 必然有大物体高速移动
- **C.** 只要用绝对差，光照变化必然被消除

<details><summary>作答后查看解释</summary>

- **A.** 只要增加训练增强，就能消除分区泄漏
- **B.** 不能，需要让group表达真实采集关联
- **C.** 能，任何group审计都能识别视觉重复

## reshape / copy：BGR行步幅 · 理解自测

BGR8宽度100，每行stride=320字节，行尾20字节应如何处理？

- **A.** 把整个buffer直接reshape(height,100,3)
- **B.** 把额外20字节当作第四个颜色通道
- **C.** 每行按320分开，只取前300字节再reshape

<details><summary>作答后查看解释</summary>

正确选项：C

- **A.** 包含padding的总字节数与目标形状不符，可能报错或错位。
- **B.** 行填充不是通道，不能按RGBA解释。
- **C.** 100个像素每个3字节，其余20是行填充。

</details>

## sum / mean / percentile：端到端延迟 · 理解自测

采集、预处理、推理、后处理完全串行，平均总耗时50ms。不含其他等待时FPS估计是多少？

- **A.** 20 FPS
- **B.** 50 FPS
- **C.** 只看最快的推理阶段即可得到端到端FPS

<details><summary>作答后查看解释</summary>

正确选项：A

- **A.** 1000/50=20，仅适用于题设串行假设；异步吞吐需实测。
- **B.** 毫秒延迟不是每秒帧数，需要取倒数并换算单位。
- **C.** 忽略采集和其他阶段会高估串行处理能力。

</details>
