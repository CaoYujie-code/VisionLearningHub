# 官方学习资料导航

核对日期：2026-10-25。这些是后续课程的参考入口，阅读链接不代表已经完成对应实践。平台将配中文解释与分步任务。

入门时按当前课程选 1～3 个入口。Bootlin 页面同时提供课程材料与实验链接；板卡资料只在实际选择该设备分支时使用。

## R01 · Python 官方教程

- 对应阶段：S00；定位：core。
- 内容：函数、循环、模块、异常。
- 资料：[Python 官方教程](https://docs.python.org/3/tutorial/)。
- 阅读任务：先读函数与控制流，再写一个筛选列表的函数。

## R02 · NumPy 学习入口

- 对应阶段：S00；定位：core。
- 内容：数组、索引、切片、数据类型。
- 资料：[NumPy 学习入口](https://numpy.org/learn/)。
- 阅读任务：创建一个二维数组，解释 shape、axis 和布尔筛选。

## R03 · OpenCV Python 教程

- 对应阶段：S01；定位：core。

- 阅读任务：按课程指定章节学习，每次输出中间图。
