# 官方学习资料导航

核对日期：2026-10-25。这些是后续课程的参考入口，阅读链接不代表已经完成对应实践。平台将配中文解释与分步任务。

入门时按当前课程选 1～3 个入口。Bootlin 页面同时提供课程材料与实验链接；板卡资料只在实际选择该设备分支时使用。

## R01 · Python 官方教程

- 对应阶段：S00；定位：core。
- 内容：函数、循环、模块、异常。
- 资料：[Python 官方教程](https://docs.python.org/3/tutorial/)。
- 阅读任务：先读函数与控制流，再写一个筛选列表的函数。

## R02 · NumPy 学习入口

- 对应阶段：S00；定位：core。
- 内容：数组、索引、切片、数据类型。
- 资料：[NumPy 学习入口](https://numpy.org/learn/)。
- 阅读任务：创建一个二维数组，解释 shape、axis 和布尔筛选。

## R03 · OpenCV Python 教程

- 对应阶段：S01；定位：core。
- 内容：图像读写、颜色、处理、几何、视频。
- 资料：[OpenCV Python 教程](https://docs.opencv.org/4.x/d6/d00/tutorial_py_root.html)。
- 阅读任务：按课程指定章节学习，每次输出中间图。

## R04 · OpenCV 图像处理目录

- 对应阶段：S02；定位：core。
- 内容：滤波、阈值、形态学、梯度。
- 资料：[OpenCV 图像处理目录](https://docs.opencv.org/4.x/d2/d96/tutorial_py_table_of_contents_imgproc.html)。
- 阅读任务：比较阈值、边缘和形态学三类输出的用途。

## R05 · OpenCV 相机标定

- 对应阶段：S03；定位：core。
- 内容：畸变、内外参、校正。
- 资料：[OpenCV 相机标定](https://docs.opencv.org/4.x/dc/dbb/tutorial_py_calibration.html)。
- 阅读任务：区分镜头畸变校正、透视映射和物理尺寸标定。

## R06 · PyTorch Learn the Basics

- 对应阶段：S05；定位：core。
- 内容：张量、数据、模型、梯度与优化。
- 资料：[PyTorch Learn the Basics](https://docs.pytorch.org/tutorials/beginner/basics/intro.html)。
- 阅读任务：画出数据、模型、损失、反向传播和更新的流程。

## R07 · PyTorch 视觉迁移学习
