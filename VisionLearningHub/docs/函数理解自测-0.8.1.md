# 函数理解自测 · 0.8.1

在0.8.0的40组函数讲解和44道基础练习上，增加40道场景/参数判断。它用于发现理解漏洞，不替代手敲实现。

## 怎么用

1. 基础练习 → 函数与场景 → 选一个函数。
2. 读调用、参数、场景和小例子，向下找到“练一练：场景与参数判断”。
3. 选最符合题设的一项，点击“检查选择并保存”。提交成功后显示逐项解释；答错也能看为什么其他选项不符合条件。
4. 选错后可点“重新思考”。函数查阅范围选“待巩固的函数”，集中复习答错或题目已更新的条目。
5. 在待巩固列表中答对后，界面切到全部函数并保留本条解析，避免刚答完就看不到解释。错题已从队列移除。
6. 回到原练习手敲代码并正式验收；理解题答对不会增加代码通关数。

覆盖的问题包括阈值严格大于、HSV环绕、形态学结构尺寸、轮廓/像素面积、中值与高斯适用条件、透视点序、类型溢出、插值类别污染、IoU与一对一匹配、stride和串行延迟等。

## 记录怎么保存

同一函数跨题共享，例如T03与V06的threshold卡共用理解记录。每条记录包含最近选择、当前题目版本的提交次数和答错次数、时间及题目修订标识。答对后仍保留曾答错次数；没有尝试的函数不会伪装成错题。

保存到本地SQLite，刷新页面、关闭面板或重启服务后可恢复。只有服务器保存成功才显示本次反馈；保存失败保留本次选择，显示错误，允许重试。跳转到其他页面会等待正在提交的选择完成。记录不改变解题源码或正式验收历史。

当题目选项或解释发生修订，旧记录显示“题目已更新”，需要重新判断。旧答案不能直接被当成新版正确答案；新版本第一次提交重新累计该版本次数。

## 备份与清理

- 平台ZIP备份包含理解自测记录；恢复时校验选项、次数、版本和时间。损坏记录会拒绝导入，保留原学习记录。
- 清理缓存：保留理解记录。
- 清除运行历史：只清代码运行历史，保留理解记录。
- 清除全部学习记录：删除理解记录，与原有课程笔记/收藏清理边界一致；仍保留原生开发文件。
- 下载本题示例与讲义：附课程自测题和折叠解析，不包含个人提交记录；个人记录通过学习备份带走。

## 学习边界

一道选择题只能检查一个理解点。答对不证明能处理所有真实场景；应继续做最小例子、改参实验以及代码多样例验收。所有题目都是离线本地教学，不需要模型API或在线判题服务。

基础功能和建议顺序见[函数学习指南](函数学习指南-0.8.0.md)，完整讲解及自测见[函数速查手册](函数速查手册.md)。
