## 本轮重点

- 首页首轮八题按当前代码验收结果推荐；学习者可自由回看。八题均有输入、输出、首次尝试与自查重点。
- 18 个术语按中文或英文搜索，附小例子与易错点；无匹配时明确提示。4 类排查指引进入已有面板，未提供图解的题目回到知识提示。
- 逐步图解隐藏原题编辑与验收区，返回任务后恢复；原题后台作业仍可停止，不误把图解导入作为通关。
- 编辑后立即切图解并刷新，原题草稿保留；原题草稿和图解笔记保存失败时均阻止切换，重试成功后可继续。
- 原生 T01 示例在独立命名空间中读取含中文和空格的 PNG 路径，核对尺寸、通道和像素；覆盖缺失文件与无效图片。
- 37 道旧图解定义与发布前 HEAD 一致；既有学习修订标识保持不变。用户已有源码不被参考实现替换。
- 桌面与窄屏截图已目视检查，路线、卡片与术语区不撑宽页面。

本轮使用隔离测试数据和 VS Code 配置；没有安装到日常配置，没有修改真实学习记录。未额外运行可选调试器断点专项。依赖版本保持不变，锁文件只修改根项目版本。

这些检查验证功能和保存行为；尚未开展真实初学者对照试用，不声称已经证明学习效率提升。
