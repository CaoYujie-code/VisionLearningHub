## 本轮验证

- 安排状态与备注独立于图解自查、代码草稿、运行次数和正式成绩；已验收题仍可保留待复习安排。
- 修改只影响指定基础题，清除本题安排可以重复执行，不删除其他题安排、代码或图解记录。
- API 拒绝未知题目、工程编号、额外字段、非法状态、错误类型和超过 1000 字备注；长度边界可保存，失败不覆盖旧记录。
- 新客户端和重启后的 VS Code 服务可读到已保存安排。
- 导出包含尚未开始图解但已有安排的题；备注原文以安全长度的 Markdown 围栏保存。
- 清除缓存和历史保留安排，清除全部移除安排；完整备份恢复后安排一致。
- 不含安排的旧备份可以恢复；含非法安排的备份被拒绝，现有记录保留。
- 浏览器验证状态筛选、备注搜索、刷新恢复、明确取消、Escape 与页面内导航保护、保存失败保留输入及重试。
- 手机编辑窗口和安排卡片无横向溢出；截图已目视检查。
- 最终 VSIX 通过接口桥接保存安排，服务重启后恢复，导出含备注，清除后正式成绩不变。
- 全部 44 道图解定义与上版完全一致，没有重置课程修订号。

测试均使用隔离学习数据与隔离 VS Code 配置，不修改真实学习记录或日常插件安装。没有新增依赖，锁文件只修改根版本。未运行可选调试器断点专项。
