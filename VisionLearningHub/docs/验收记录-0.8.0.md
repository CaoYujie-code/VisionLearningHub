## 验证边界

- 40组覆盖当前课程核心函数和算法组件，不是整个OpenCV/NumPy函数库。示例不等于完整题解。
- 小实验使用确定的小数组或合成图，不证明真实工程鲁棒性；算法场景限制在每组讲解中说明。
- E07中间图自动检查存在和尺寸，标注语义仍需目视检查；仅完整工程正式验收计通关。
- 函数示例为独立开发文件，平台清理不删除；课程ZIP导出原版示例，自己的改动请另存或用Git管理。
- YOLO任务仍为离线数据/后处理，Linux任务仍为离线契约练习；本次没有声称新增真实训练或实机驱动操作。
