## 本版重点

- 保存旧 37 道定义哈希快照，并与发布前定义逐项核对一致，旧学习修订标识保持兼容。
- T11 三种旋转配置均得到身份 [2,0,3,1]，旋转列变化；逐格用标量均方差公式对照误差表。
- 用 0 与 255 的差验证先转浮点，避免 uint8 回绕；覆盖空图块列表和并列最小误差的确定性选择。
- T13 无扰动系数与已知仿射公式一致；扰动幅度从 2 到 8，检查误差按四倍变化；拟合残差与设计列正交。
- 共线点、只有一或两个点均在拟合前拒绝。改动独立检查真值不改变预测，空检查点保留 (0,2) 输出和 (0,7) 表形状。
- 数值表列名与宽度一致；实验包参数可还原相同输入，图形显示不替代原始数据。
- 浏览器覆盖每一步真实图、改参、黑色零差图、原生参考脚本导入、修改系数后的首个差异定位、笔记和诊断刷新恢复。
- 手机七列表格可横向阅读，页面不被撑宽；截图经目视检查。VS Code 中新两题独立脚本的所有导入步骤与教学数组一致，正式成绩不改变。

使用隔离测试数据与 VS Code 配置；没有安装到日常扩展目录，没有修改真实学习记录。本轮未额外运行可选调试器断点专项。依赖保持不变，锁文件只改变根项目版本。
