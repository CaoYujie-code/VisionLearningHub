## 新功能检查

- 场景、目标、适用边界、每步代码、逐行解释、观察点、故障线索、预测与解释均有具体内容。
- 27 组参数由真实 OpenCV 运算生成。阈值题独立验证 99 / 100 / 101 在阈值 100 下输出 0 / 0 / 255。
- Sobel 保留浮点负值和超 255 数值；预览显示变换与原始范围同时说明。跨进程浮点比较使用小容差，预览允许 1 灰度级舍入差。
- 独立脚本只使用 OpenCV、NumPy 和 Python 标准库；同输入、同参数生成的数组和预览与平台一致。
- 部分运行或空脚本导入只展示实际保存的步骤，未保存步骤不会用教学图补齐。
- 拒绝未知文件、路径穿越、错误题号、错误输入标识、损坏数组、非有限值、超限参数和缺少会话凭证；失败不覆盖上次有效导入记录。
- NPY 头先验证类型、形状与字节数，再读取数组；不执行导入代码、不使用 pickle。
- 图解位置、模式、参数、观察笔记与自评持久化；备份恢复后导入图片仍可读取；清全部删除学习状态但保留原生源码。
- 保存失败显示错误、保留笔记并阻止离开；重试成功后可继续。参数与版本不一致时不静默并排比较。
- VS Code 直接打开、运行、读取实验，重复打开保留个人修改和原题源码；运行前保留旧结果副本，提前报错后不会误读旧结果。
- 桌面与 390px 手机布局截图并目视确认，长代码在自身容器内滚动。
