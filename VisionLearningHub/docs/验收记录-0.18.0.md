## 本轮检查

- 四组输入的选择 / 合法数量分别为 `[2,1]`、`[0,1]`、`[-1,0]`、`[1,2]`。
- 每个候选的分数对照正式 T09 参考实现；正式 T10 使用依赖调用时返回相同下标，并且不修改父参数。
- 默认分数为 `[[0,.9,0],[1,1,.1],[2,1,0],[3,1,.1]]`，目标外的 1000 个重叠像素不能被目标 ROI 裁掉。
- 同时满足约束，包含 `coverage=.98`、`overlap=.02` 的边界；邻近越界值拒绝。
- 空候选、空布局、多个合法下标、候选重排分别检查；无解不索引末项，也不画出最后一个候选。
- int32 累计可保留 300 次覆盖，浮点坐标取整与正式评价器一致。
- 四组独立实验包仅用原生库执行，五个保存数组真实导入；不更改正式成绩。
- 浏览器验证五步图片、中文列名、场景切换、错误索引定位、笔记与导入恢复、窄屏和返回原题。
- 41 道旧定义逐项与上版一致，并存储修订哈希快照；已有学习记录键和成绩规则未变。
- 截图目视校对后加强候选编号可读性，并注明不同场景的观察下标；完整回归使用最终定义。
