## 插件内更新的真实验证

测试基于本次完整 VSIX，在临时目录创建后继版本的测试包，模拟 GitHub 下载响应。安装前实际执行摘要、包身份与版本校验，然后调用 VS Code 官方 `workbench.extensions.installExtension` 命令。

安装后在隔离扩展目录中找到新版文件，证明无需人工使用“从 VSIX 安装”。测试包没有上传 GitHub，也没有安装到用户的日常扩展目录。

此测试验证下载响应到真实安装的链路；GitHub 账号授权、远程网络和正式 Releases 可用性仍取决于仓库配置。正式发布工作流随版本标签运行，不能把本机测试等同于远程发布成功。
