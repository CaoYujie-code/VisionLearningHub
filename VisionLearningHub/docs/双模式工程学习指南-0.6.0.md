# 双模式工程学习指南（0.6.0）

本版共有44道基础练习、8个工程、40个可验证任务块、32章课程。新增E05颜色分拣、E06平面尺寸测量、E07纹理标签定位、E08九宫格拼图恢复。当前交付为方案的前两批；YOLO训练与Linux实机部署工程仍属后续工作。

## 两种方式共享源码

在“工程项目”打开案例，选择“分块引导”或“独立挑战”。切换只保存学习方式，不复制、不重置代码。
独立挑战可以直接编辑main.py和自定义模块，随时运行完整验收，不需要完成分块勾选。
分块引导提供当前任务、输入输出约定、前置题、官方资料、两层提示和单独检查按钮。参考工程仍默认收起，可逐文件查看，不能一键覆盖学习者代码。

## 五个任务块

| 块 | 入口与输出 | 验证范围 |
| --- | --- | --- |
| 读写 | checkpoint.py --block io；records含file、shape、dtype，roundtrip保存无损回读PNG | 两批输入、坏文件、尺寸/类型和像素一致性 |
| 算法 | checkpoint.py --block detect；输出工程约定的records | 两批输入的定位/分类/尺寸/拼图结论；不要求overlay或校正图；E04只检查逐帧检测，不要求ID连续与事件 |
| 可视化 | checkpoint.py --block render；读取_detections.json，输出records及overlays | 结果传递、输出尺寸和可见标注；标注位置与语义需人工结合图像复核 |
| 批处理 | main.py | 自己的完整流程、一个开发批次、全部工程输出 |
| 完整验收 | main.py | 五个正式批次；唯一能授予完整工程通过状态的检查 |

前三块只需实现当前分支。checkpoint.py是普通可编辑Python文件，允许调用自行定义的函数和模块；不得在模块导入时执行尚未完成的流水线。平台不提供专属图像处理函数。独立挑战不依赖checkpoint.py。

可视化块提供两种输入：

- 标准检测结果：教学参考程序生成，先隔离学习绘图。报告和进度明确标记为标准输入，不代表自己的检测通过。
- 自己的检测结果：先运行并检查自己的detect分支，再把结果交给render。检测失败时提示先修复上游。

平台检查按钮自动准备输入。终端和导出项目可使用以下命令：

```sh
python checkpoint.py --block io --input data/sample --output step-io --config config.json
python checkpoint.py --block detect --input data/sample --output step-detect --config config.json
python checkpoint.py --block render --input data/standard --output step-render --config config.json
python main.py --input data/sample --output output --config config.json
```

data/standard随工程ZIP导出，包含开发图片与_detections.json。要在终端使用自己的结果，将detect生成的results.json复制到输入目录并命名为_detections.json。请使用新输出目录，避免将旧产物混入手动观察。

## 新案例的具体范围

| 工程 | 训练重点 | 约束 |
| --- | --- | --- |
| E05 颜色分拣 | HSV范围、红色跨端点、区域筛选、类别中心 | 真实纹理背景上的合成零件；无严重反光/重叠 |
| E06 尺寸测量 | 标尺定位、像素到毫米、旋转矩形、缺标尺拒绝 | 正视同一平面；缺标尺必须返回no_reference，不宣称现场计量精度 |
| E07 标签定位 | ORB/Hamming匹配、RANSAC、模板四角映射、漏贴 | 实拍纹理生成标签与场景；不含低纹理/严重遮挡 |
| E08 拼图恢复 | 固定网格切分、四方向比较、身份唯一性 | 0..8行优先编号；rotation为恢复时顺时针角度；覆盖缺块与重复块，无自由散落检测或机械执行 |

E05/E06对象为合成图形；E07/E08使用已有公开硬币照片制作标签和图块。所有变体与来源说明可查，无新增运行依赖。这些数据不是独立现场数据集。

## 记忆与进度

保存学习方式、当前任务块、可视化输入来源、提示展开层级、原有阶段自评及复盘笔记。阶段自评不等于代码通过。
任务块检查历史保存在已有SQLite与ZIP备份中。状态区分尚未检查、当前源码通过、需要修改、源码已变需重验。
当前按工程所有根目录Python文件和config.json的快照保守判断失效；改动任意模块会提示任务块重新检查。仅修改笔记或切换模式不影响代码成绩。
历史报告保留；标准输入与自己的输入分别记录。完整工程成绩只看正式验收，不由任务块数量推导。

## 旧工程升级

0.5.0已有源码不会被升级自动改写。旧工程需要分块入口时，点击“添加分块入口”，只创建缺少的checkpoint.py；已存在同名文件时保留它。
新增入口会改变工程源码快照，因此旧成绩保留为历史，需要重新验收。仍希望保持原结构的学习者可以直接使用独立挑战。
恢复备份沿用源码暂存机制，不覆盖VS Code当前文件。清除记录保留源码和开发素材。

推荐先用E05练习一次读写、算法、标准绘图、自己的绘图、批处理、完整验收，再用E08独立挑战检查自己是否掌握模块拆分。
