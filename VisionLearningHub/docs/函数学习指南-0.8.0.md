# 函数学习指南 · 0.8.0

你已经有44道基础题。本版补足“看到函数名却不知道如何使用”的缺口，提供40组课程核心函数及算法组件讲解，不增加新的基础题数量。

## 从哪里打开

基础练习 → 选题 → **先学本题函数怎么用**，或点击 **函数与场景** 页签。默认只显示当前题需要的函数，可切换全部40组，并搜索函数名、参数或场景。相关题按钮会跳到对应练习；左上角返回保留原题的函数页、选中项和搜索状态。

每组都有调用形式、关键参数表、返回值及shape/dtype、适用场景、方法限制、常见错误、最小例子、预期结果、改一处参数的实验、官方链接。它是课程所需接口的教学说明，不是OpenCV/NumPy所有函数及所有重载的全集。

## 推荐一次怎样学

1. 看本题的方法选择说明，说出为什么要用它。
2. 读参数表，圈出你不理解的shape、dtype、坐标、阈值单位。
3. 先预测例子的输出，再在独立文件手敲并运行。例子自带小数组/合成图，无需下载照片，不依赖平台辅助函数。
4. 只改变实验指定的一处参数。示例中的assert描述原条件，改输入后应先预测，再相应修改断言，不能把预期失败直接当库出错。
5. 到笔记记录“输入条件 → 预测 → 实测 → 不适用条件”，再回练习编辑器完成solve，并做多样例验收。

示例通过只证明这个小实验，不会增加基础题或工程的正式通关进度。参考答案仍单独放在知识与提示里。

## 原生编辑器和离线使用

在VS Code插件内点击“在 VS Code 打开独立示例”，会在当前学习空间的 `function-examples/题号/函数组.py` 创建文件。再次打开保留已有内容，不覆盖你的参数实验。它与 `exercises/题号.py` 分开。选择已有OpenCV/NumPy解释器后使用Python运行入口或终端执行该文件；不安装新环境、不修改你的日常编辑器配置。

自己修改的独立示例请另存或用Git管理；课程讲义ZIP和代码工程中的函数示例是课程原版，不包含这些文件的个人修改。

网页和插件均可下载当前题示例ZIP，含普通.py和README，可在VS Code、PyCharm或命令行运行。平台“导出代码工程”还会附带全部44题的函数示例与讲义。外部官方资料需要联网，讲解和小例子可离线使用。示例文件属于自己的开发文件；平台清理进度不删除它们，也不将它们当解题源码。

网页旧题的read_image/student属于平台辅助入口，不是cv2函数；原生/导出工程使用显式解码或普通import。函数卡会说明区别。

## E07如何接上基础

E07共有10个任务块：读写、ORB特征、Hamming筛选、RANSAC定位、整合检测、绘图、方法对比、故障维修、批处理、完整验收。新增细分入口是普通 `feature_steps.py`，可任意拆分内部函数。

旧工程点击“添加细分入口”补文件，已有模块不会覆盖。匹配/定位可用标准上游数据隔离学习，也能接自己的上游实现；自己的上游先检查再交给下游。报告分别保存来源、测量事实、失败排查建议和中间图。绘图只自动检查文件存在与尺寸，标注语义还需目视复核。

导出的 `data/feature_standard` 提供标准特征、匹配与对比/维修输入，`FEATURE_STEPS.md` 写明各分支协议。空图、坏图与不足两个邻居都有边界练习。对比同时区分全点拟合残差与独立四角误差，避免只凭一个较小数字判断算法好坏。仍以main.py的五批完整验收决定工程通关。
