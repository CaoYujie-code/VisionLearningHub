## 数据与验收边界

- 硬币照片与砖墙/碎石纹理来自固定版本公开资源；前者上游注明无已知版权限制，后两者注明CC0。下载URL、许可依据及摘要见 `content/engineering/sources.json`。
- 缺陷、单据内容与运动序列为教学合成；验收批次由少量同源图片派生，不代表独立工厂数据集或真实相机泛化表现。E02要求图像已对齐；E03不含OCR；E04不含复杂遮挡重识别。
- 工程真值由人工中心标注或场景生成参数得到，不调用学生检测函数。错误数量、几何位置、缺失输出、ID更换和重复计数均有拒绝测试。
- E01/E03自有图片没有标注真值，只验证运行与交付格式，不计入正式通关。
- 源码指纹涵盖工程根目录Python文件与config.json；改动辅助模块会使旧通过记录失效，修改理论前置题不会影响独立工程成绩。
- 允许保存尚未写完的配置草稿，运行时报错；不因JSON编辑中途无效而阻断平台读取工程。
- 恢复备份把工程代码放入restored-code供人工比较；清除学习记录保留工程源码和样例。未改变原有题目的验收指纹版本。
- 首轮浏览器测试发现报告晚于状态标签渲染的等待竞态，补充报告等待后完整复跑通过。新增工作区测试修正执行顺序后完整复跑通过。
- 更新安装在隔离VS Code目录内验证；远程Release状态单独核对，不以隔离测试替代发布验证。
