## 已修复的集成问题

- Windows 托管模式监听父进程管道时，标准输入继承可能阻塞创建验收子进程。改为显式空标准输入，退出监听使用文件描述符读取；真实宿主与浏览器回归通过。
- 普通 Python 导入需指向本次提交快照，避免组合题执行另一版本依赖。
- 插件模式恢复旧 ZIP 时，代码另存待比较，避免覆盖编辑器文件。
- 新增测试兼容 Windows CRLF，但源码保护比较使用保存后的原始内容。

## 边界

本轮验证的是本机 VSIX、桌面 VS Code 和网页使用，不代表已发布到 Marketplace、已完成 WSL/SSH、真实 YOLO 训练推理、摄像头、开发板或独立 EXE 验收。GitHub Actions 配置随源码提交，远程运行结果需以对应提交的 Actions 页面为准。

禁用或卸载使用 VS Code 标准界面，按其提示重载窗口。源码和记录不会因卸载自动删除；使用清除入口时需明确确认范围。
