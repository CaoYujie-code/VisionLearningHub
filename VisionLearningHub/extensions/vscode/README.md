# Vision Learning Hub · 视觉学习

**0.9.0：每一步都看清楚。** 首批 8 道基础题增加 18 个逐步图解：场景、处理前后图、代码与逐行解释、观察方向、错误排查和预测问题。支持同图缩放对照、27 组参数配置、默认参数比较、分步手敲与真实结果导入。观察笔记和学习位置本地记忆，正式题目成绩独立。详见[逐步图解指南](../../docs/逐步图解学习指南-0.9.0.md)。

**0.8.1：把会读函数变成会选方法。** 新增40道场景/参数理解自测，每个选项都有解释；本机保存提交次数和答错次数，支持跨题共享、待巩固筛选、备份恢复和题目更新后的重新判断。自测与代码验收进度分开。详见[使用指南](../../docs/函数理解自测-0.8.1.md)。

0.8.0 为现有 **44 道基础题**增加“函数与场景”：**40 组函数/算法组件讲解**，包含关键参数、输入输出类型、适用与不适用场景、常见错误、可独立运行的断言示例、改参实验和相关题目跳转。可按函数名或场景搜索，下载本题 Python 示例与离线讲义；VS Code 可直接打开独立示例，已有修改保留。阅读与示例运行不计通关。

E07 新增 ORB 特征、Hamming 筛选、RANSAC 定位、拟合对比、匹配器维修五个可自动检查的细分块，现有工程共 **50 个任务块**。匹配与定位可用标准或自己的上游结果；两类记录分开，完整工程仍需正式验收。

[函数学习指南与推荐顺序](../../docs/函数学习指南-0.8.0.md)

可选安装的本地学习扩展：33 章课程、44 道 Python 练习与9个多文件工程、12 种 OpenCV 图像实验、35 份官方资料、资料收藏与 SQLite 学习记录。

安装 VSIX 后，在 VS Code 打开学习文件夹，点击“视觉学习”。用 **Vision: Python 环境设置与检查** 配置 Python 3.12 和项目依赖。Python / Pylance / Python Debugger 由用户自行选择安装，不会自动强制安装。

课程、图像和报告在学习面板中查看；代码位于 `.vision-learning/exercises/`，直接在原生编辑器编写。支持终端运行、断点调试、面板验收和测试资源管理器。

“记录与设置”支持备份恢复和三种清除范围，需要输入 `CLEAR`；清除记录保留源码。单题重置需另外确认，并先备份原代码。

禁用或卸载使用扩展面板标准操作，按提示重载窗口。学习记录和源码保留，需要时在卸载前主动导出或清除。后台服务随扩展停用关闭。

当前未上架扩展市场。完整安装、依赖、数据路径及功能边界见 [项目 README](https://github.com/CaoYujie-code/VisionLearningHub#readme)。YOLO 训练推理与板端联调尚未接入；Python 代码按当前用户权限执行。

0.3.1 支持 GitHub Releases 更新：执行 **Vision: 检查插件更新**；也可开启每 24 小时检查，新版本由用户点击后安装，无需手动导入。设置 `visionLearning.checkUpdates` 可关闭自动检查。私有仓库需通过 VS Code 登录有权限的 GitHub 账号。

0.4.0 新增缩放与增强、连通域、距离图、模板定位、HSV 环绕、帧差、数据划分审计、检测匹配、行步幅与延迟统计练习。学习路线可搜索知识点与题号；保留旧代码、笔记和通关记录。相机标定、特征匹配、光流与量化部署提供分步骤扩展任务，实机能力另行验收。

0.6.0 新增工程项目入口：批量计数、表面缺陷、单据校正和过线跟踪。你可以创建自己的函数与模块，读取内置公开图片、输出JSON/标注图，导出后在VS Code/PyCharm独立运行。每个项目5个实施阶段、5批验收输入，保存源码、阶段记录与复盘。

支持9个工程、50个可验证任务块与独立/引导双模式。切换模式保留代码，标准输入练习与完整工程成绩分开记录。

0.7.0 新增相机标定工程、37个专属小任务、9组对比实验与9道维修练习。基础练习入口始终回到基础题；复习前置题后可返回原工程任务。面板关闭后保留基础/工程位置和代码标签，页面切换前保存草稿；自查不计自动验收。
