# Changelog

## 0.5.0

- 新增4个多文件工程、20个实施阶段：批量硬币计数、纹理缺陷、单据校正、过线跟踪。
- 内置有出处与SHA-256的公开图像，明确标记生成的教学变体。
- 支持工程源码与配置编辑、添加模块、阶段记录、原生运行/调试及导出。
- 以JSON、逐图结果、连续ID和输出图片验收完整工程；自有图片探索不计通关。
- 备份恢复保留现有工程源码，新增工程使用同一插件更新渠道。

## 0.4.0

- 课程由16章扩展至24章，每章增加适用场景、失败条件和实验步骤。
- 新增12道原生Python练习，共44题、220组正式验收样例。
- 新增11份官方资料，共35份；学习路线可搜索标题、知识点和题号。
- 新增数据划分审计、检测一对一匹配、图像行步幅和延迟统计练习。
- 保留原练习、笔记与通关记录；兼容网页和VS Code插件内更新。

## 0.3.1

- 新增 GitHub Releases 检查、SHA-256 与包身份校验及插件内更新安装。
- 增加版本标签自动发布工作流与版本同步脚本。
- 持久化最后阅读位置，提供续学入口、课程进度和状态栏进度。
- 服务退出时提示重启，环境诊断按依赖显示结果。
- 运行或调试期间阻止清除与重置；隔离环境验证真实升级安装。

## 0.3.0

- 新增可选安装的 VS Code 学习扩展及 VSIX 打包。
- 复用课程、资料、图像实验、笔记、备份与历史界面。
- 支持真实文件编辑、Python 调试、终端任务和测试资源管理器。
- 增加分范围清除与带代码备份的单题重置。
- 保留网页版；插件恢复备份时不覆盖 IDE 源文件。
